# Effectful Technologies

> Effectful Technologies builds the Effect ecosystem — a set of open-source TypeScript
> libraries for writing production-grade software. The flagship `effect` library is a
> composable standard library and execution engine that unifies error handling, resource
> management, concurrency, dependency injection, observability, and testability. Effect is
> described by the company as "Layer 0" of a broader vision extending into distributed
> systems: RPC, SQL, clustering, and durable execution. Distributed via npm; not an HTTP API.
